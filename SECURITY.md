# Security policy

Please do not disclose vulnerabilities, credentials, private paths, or proof-of-concept details in a public issue.

Use GitHub's private vulnerability reporting for this repository when it is available. If private reporting is not enabled, open a minimal public issue requesting a private contact channel and include no sensitive details. The maintainer will coordinate a safer reporting path.

Field-sidekick intentionally avoids offensive automation, credential handling, and remote/network actions. Reports involving accidental expansion into those areas are especially welcome.
