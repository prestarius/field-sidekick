# Roadmap

## Iteration 2 — core/module foundation

- Typed check/result model with PASS/WARN/FAIL/SKIP.
- CommandRunner and platform boundary.
- Module registry.
- System, dev, network and wireless modules.
- Desired-state workstation profile.
- Scoped doctor commands, module listing and config inspection.
- Expanded deterministic tests.

## Iteration 3 — workstation actions

- `field install` and `field apply` primitives.
- Idempotent package/service operations.
- Dry-run/plan output and explicit confirmation.
- Rollback-aware configuration changes where practical.

## Iteration 4 — developer and AI workstation

- Git/GitHub, uv/Python, Docker.
- Claude Code, Codex and editor integrations.
- Version and configuration checks.

## Iteration 5 — networking and wireless

- Alfa AWUS036ACM / MT7612U visibility.
- Driver/interface health.
- Authorized lab-oriented wireless setup helpers.

## Iteration 6 — personal infrastructure

- Tailscale, Syncthing and Obsidian.

## Iteration 7 — ESP32 field devices

- T-Deck Plus, T-Embed CC1101 Plus, PlatformIO and firmware inventory.

## Iteration 8 — browser and OPSEC profile

- Firefox profiles and workstation compartmentalization.
